# Mamaearth Returns & Growth Intelligence Pipeline

## Project Overview & Architecture
This repository contains an end-to-end data pipeline built to investigate how returns impact profit margins on Mamaearth orders. Designed using the **DataNarrator Agentic Pattern**, this system ensures strict data integrity: all arithmetic is deterministically processed via SQL and Python, while Generative AI is strictly isolated to synthesizing verified metrics into an executive narrative. 

### Goal-Oriented Workflow Design (CLEAR Framework)
* **Goal**: Process raw order data, identify the true outlier-corrected revenue peak, calculate return rates across payment/city segments, and output a 3-section Situation-Complication-Resolution (SCR) executive brief.
* **Constraints**: The GenAI model is explicitly restricted from hallucinating numbers; it relies solely on programmatic JSON context.
* **3-Way Validation**: The system accounts for the **Happy Path** (clean execution), **Edge Cases** (flagging bulk outliers and 5 duplicate drops), and **Failure Cases** (a keyless, deterministic Offline Fallback if the Gemini API returns a 503 error).
